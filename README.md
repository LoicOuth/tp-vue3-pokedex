# 🧬 Vue 3 Pokedex — Projet de TP

Une application Pokedex simple développée avec **Vue 3**, **TypeScript** et **Vue Router**, utilisant l'API [Tyradex](https://tyradex.vercel.app/) pour récupérer les données des Pokémon.

---

## 📦 Stack technique

- ⚙️ Vue 3
- ✨ Composition API
- 🔡 TypeScript
- 🌐 Vue Router
- 🌱 Fetch API (HTTP)
- 💎 Composants réutilisables

---

## 🎯 Fonctionnalités

- ✅ Affichage d'une **liste de Pokémon**
- ✅ **Navigation** vers une page de détails pour chaque Pokémon
- ✅ Utilisation d’un **composant dédié** par carte de Pokémon
- ✅ Architecture **modulaire et propre** via la Composition API

---

## 🚀 Installation

```bash
# Création du projet (si ce n’est pas encore fait)
npm create vue@latest pokedex
cd pokedex

# Installer les dépendances
npm install

# Lancer le serveur de dev
npm run dev
```
